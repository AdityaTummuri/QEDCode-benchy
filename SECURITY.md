# Security

Please report vulnerabilities through GitHub's private vulnerability reporting
(**Security → Report a vulnerability** on this repository), never in a public issue. You will get
an answer within a week.

In scope: a suite, submission or report that makes Benchy run something it should not, leaks
data the sharing allowlist excludes, or passes validation while holding secrets or personal data;
anything that lets a benchmark task see its hidden tests.

The private fresh suites are never in this repository; a report that one leaked is in scope too.
